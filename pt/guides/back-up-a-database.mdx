---
title: Fazer backup de um banco
icon: box-archive
description: Crie e restaure backups de banco de dados com segurança.
---

Backups protegem seus dados antes de migrações, mudanças de schema, rotação de senha ou qualquer manutenção arriscada em produção.

## Criar um backup

```bash
curl -X POST https://api.hyzecloud.com/api/databases/db_001/backups \
  -H "Authorization: Bearer hyze_sua_chave"
```

Liste os backups existentes com `GET /api/databases/:databaseId/backups` e baixe qualquer um com `GET /api/databases/:databaseId/backups/:backupId/download`.

## Restaurar

```bash
curl -X POST https://api.hyzecloud.com/api/databases/db_001/restore \
  -H "Authorization: Bearer hyze_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{ "backupId": "backup_db_001" }'
```

<Callout type="warning">
  A restauração substitui os dados atuais do banco de destino. Confira o `databaseId` antes de executar em produção.
</Callout>

## Rotina recomendada

- Backup manual antes de toda mudança de schema ou import grande
- Backup antes de rotacionar a senha do banco
- Baixe (`download`) backups importantes para armazenamento externo — não dependa só da plataforma
