A **chave de API** é sua credencial de acesso à Hyze Cloud. Ela identifica seu workspace e autoriza cada requisição à API. Sem uma chave válida, nenhuma chamada é aceita.

## Criar uma chave

<Steps>
  <Step title="Abra o dashboard">
    Entre em [hyzecloud.com/dashboard](http://hyzecloud.com/dashboard).
  </Step>
  <Step title="Vá em Settings → Developer">
    O painel lista todas as chaves do workspace com nome, prefixo (`hyze_…`), última utilização e data de criação.
  </Step>
  <Step title="Clique em New key">
    Dê um nome que identifique o uso, como `CI/CD Produção` ou `Scripts internos`.
  </Step>
  <Step title="Copie e guarde o secret">
    A chave completa aparece **apenas uma vez**. Salve em um gerenciador de segredos ou variável de ambiente. Se você perder, será preciso revogá-la e criar outra.
  </Step>
</Steps>

<Callout type="warning">
  Depois da criação, só o prefixo (`hyze_…`) fica visível no dashboard. Revogue imediatamente qualquer chave que possa ter vazado.
</Callout>

## Autenticar uma requisição

Envie a chave no header `Authorization` com o esquema `Bearer`:

```http
Authorization: Bearer hyze_sua_chave
```

```bash
curl https://api.hyzecloud.com/api/apps/ \
  -H "Authorization: Bearer $HYZE_API_KEY"
```

Com a SDK, passe a chave uma vez na inicialização:

```ts
import { HyzeCloud } from "@hyze-cloud/sdk";

const hyze = new HyzeCloud({ apiKey: process.env.HYZE_API_KEY });
```

<Tip>
  A URL base da API é `https://api.hyzecloud.com/api`. O mesmo endpoint serve a todos os ambientes — o workspace é determinado pela chave usada na requisição.
</Tip>

## Quando algo dá errado

Você recebe **HTTP 401** quando:

- A chave não é enviada no header `Authorization`
- A chave está incorreta ou foi revogada
- O header não segue o formato `Bearer hyze_...`

## Boas práticas

- Guarde chaves em variáveis de ambiente (`HYZE_API_KEY`), nunca no código ou no front-end
- Use uma chave por ambiente ou automação (CI, local, tooling de produção)
- Use nomes descritivos — eles aparecem na lista e ajudam a revogar a chave certa
- Revogue chaves que não usa mais

## Gerenciar chaves pela API

Além do dashboard, você pode criar, listar, atualizar e revogar chaves pelos endpoints de [API keys](/api-reference/api-keys).
