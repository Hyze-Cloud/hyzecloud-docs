title: Provisionar um banco de dados

---

A Hyze provisiona PostgreSQL, MySQL, MongoDB e Redis pela mesma API. O fluxo: criar a instância, receber a string de conexão, injetá-la no app.

## Criar o banco

<Steps>
  <Step title="Escolha um engine">
    `postgresql`, `mysql`, `mongodb` ou `redis`.
  </Step>
  <Step title="Crie a instância">
    ```bash
    curl -X POST https://api.hyzecloud.com/api/databases/ \
      -H "Authorization: Bearer hyze_sua_chave" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "prod-postgres",
        "engine": "postgresql",
        "memoryMB": 1024,
        "storageGB": 20
      }'
    ```
  </Step>
  <Step title="Guarde a string de conexão">
    Copie o `connectionString` da resposta e salve como variável de ambiente do seu app. Mínimos: 256 MB de memória e 1 GB de armazenamento.
  </Step>
</Steps>

<Callout type="warning">
  Trate a string de conexão como segredo. Não a commite nem cole em logs.
</Callout>

## Conectar a um app

```bash
curl -X PUT https://api.hyzecloud.com/api/apps/app_001/env \
  -H "Authorization: Bearer hyze_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{
    "envVars": {
      "DATABASE_URL": "postgresql://user:pass@host:5432/db"
    }
  }'
```

Reinicie o app para que a nova variável seja injetada.

## Verificar o resultado

- Status: `GET /api/databases/:databaseId` — aguarde `status: running`
- Estatísticas: `GET /api/databases/:databaseId/stats`

## Problemas comuns

<AccordionGroup>
  <Accordion title="O banco ficou preso em provisioning">
    A criação é assíncrona — a resposta traz um `operationId`. Acompanhe com `GET /api/databases/:databaseId/operations`.
  </Accordion>
  <Accordion title="O app não conecta no banco">
    Confirme que o app foi reiniciado depois de receber `DATABASE_URL` e que a string aponta para a instância certa.
  </Accordion>
  <Accordion title="Perdi a senha do banco">
    Rotacione com `POST /api/databases/:databaseId/rotate-password` e atualize a variável no app.
  </Accordion>
</AccordionGroup>
