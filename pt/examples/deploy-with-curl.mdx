title: Deploy com curl
icon: terminal
description: Faça deploy de um artefato ZIP usando apenas curl — o caminho mínimo para CI.
---

Este é o menor caminho de deploy para sistemas de CI que produzem um artefato ZIP: um `curl`, nada de SDK.

## Deploy

```bash
export HYZE_API_KEY="hyze_sua_chave"

curl -X POST https://api.hyzecloud.com/api/apps/deploy \
  -H "Authorization: Bearer $HYZE_API_KEY" \
  -F "file=@app.zip" \
  -F "name=my-api" \
  -F "runtime=node" \
  -F "memoryMB=512" \
  -F "exposePort=3000"
```

`startupCommand` é opcional. Omita (ou use `auto`) e a Hyze detecta o comando certo. Override só se precisar:

```bash
  -F "startupCommand=node server.js"
```

## Em um script de CI

```bash
#!/usr/bin/env bash
set -euo pipefail

response=$(curl -sf -X POST https://api.hyzecloud.com/api/apps/deploy \
  -H "Authorization: Bearer $HYZE_API_KEY" \
  -F "file=@app.zip" \
  -F "name=my-api" \
  -F "runtime=node" \
  -F "memoryMB=512" \
  -F "exposePort=3000")

echo "Deploy enviado: $response"
```

`set -euo pipefail` garante que o pipeline falhe se o deploy falhar — sem deploy silenciosamente quebrado.

## Verificar

```bash
curl https://api.hyzecloud.com/api/apps/ \
  -H "Authorization: Bearer $HYZE_API_KEY"
```
