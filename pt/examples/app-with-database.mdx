Exemplo ponta a ponta para APIs que precisam de armazenamento persistente: provisionar PostgreSQL e anexá-lo a um app como `DATABASE_URL`.

## 1. Criar o banco

```bash
curl -X POST https://api.hyzecloud.com/api/databases/ \
  -H "Authorization: Bearer hyze_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "prod-postgres",
    "engine": "postgresql",
    "memoryMB": 1024,
    "storageGB": 20
  }'
```

Na resposta, guarde `database.id` e `database.connectionString`.

## 2. Definir a variável do app

```bash
curl -X PUT https://api.hyzecloud.com/api/apps/app_001/env \
  -H "Authorization: Bearer hyze_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{
    "envVars": {
      "DATABASE_URL": "postgresql://user:pass@host:5432/db"
    }
  }'
```

## 3. Reiniciar e verificar

```bash
curl -X POST https://api.hyzecloud.com/api/apps/app_001/restart \
  -H "Authorization: Bearer hyze_sua_chave"
```

Confirme que o app subiu com `GET /api/apps/app_001` e que o banco está `running` com `GET /api/databases/db_001`.

<Callout type="info">
  Variáveis de ambiente são injetadas na inicialização. Sem o restart, o app continua sem ver `DATABASE_URL`.
</Callout>
