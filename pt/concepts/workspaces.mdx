Um workspace é o limite do seu time e recursos na Hyze Cloud. Tudo o que você cria — apps, bancos, chaves — pertence a exatamente um workspace.

## O que pertence a um workspace

- Apps
- Bancos de dados
- Membros do time e convites
- Planos e uso
- Chaves de API

## Como o workspace é determinado

Cada chave de API fica ligada a um workspace. Requisições autenticadas por chave usam automaticamente os recursos daquele workspace — você não precisa passar `workspaceId` na maioria dos casos.

Quando uma sessão de browser não está presente e o endpoint suporta, é possível mirar outro workspace com o parâmetro `?workspaceId=`.

## Quando criar mais de um

Separe workspaces quando quiser isolar:

- Projetos pessoais e clientes diferentes
- Produção e testes
- Times com acesso independente

Cada workspace tem plano e faturamento próprios.
