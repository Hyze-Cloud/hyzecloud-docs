Um app é a unidade principal que você publica na Hyze Cloud: uma API, worker, dashboard, bot ou serviço em background rodando em um container gerenciado.

## O que um app inclui

Cada app carrega:

- Configuração de runtime (`node`, `bun` ou `python`)
- Variáveis de ambiente
- Logs e histórico de builds
- Backups
- Acesso ao sistema de arquivos

```json
{
  "name": "api",
  "runtime": "node",
  "memoryMB": 512,
  "exposePort": 3000
}
```

`startupCommand` é opcional. Omita (ou use `"auto"`) e a Hyze detecta como iniciar o app — Vite, Next, Node, site estático e Python são reconhecidos automaticamente. Passe um comando custom só quando precisar sobrescrever a detecção.

## Como um app roda

Todo request a um app publicado passa pelo proxy da Hyze antes de chegar no seu container. O proxy resolve o subdomínio, aplica rate limits e encaminha o tráfego para a porta exposta.

```text
Cliente → proxy Hyze → seu container
```

Isso significa duas coisas na prática:

- Seu app deve escutar em `0.0.0.0`, não em `localhost`
- A porta configurada em `exposePort` deve ser a mesma em que seu servidor escuta

## Limites

- Memória configurável por app (`memoryMB`)
- Rate limits no proxy público: 80 req/s por IP e 400 req/s por host — veja [Rate limits](/pt/concepts/rate-limits)
