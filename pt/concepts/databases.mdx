A Hyze Cloud provisiona e opera bancos gerenciados dentro do seu workspace. Você cria a instância pela API ou pelo dashboard, recebe uma string de conexão e a injeta no seu app como variável de ambiente.

## Engines disponíveis

| Engine | Uso típico |
| --- | --- |
| PostgreSQL | Dados relacionais, o padrão para a maioria das APIs |
| MySQL | Dados relacionais com ecossistema MySQL |
| MongoDB | Dados documentais |
| Redis | Cache, filas e contadores |

## Como os apps se conectam

Na criação, a Hyze retorna uma `connectionString`. Guarde-a como variável de ambiente do app:

```json
{
  "name": "prod-postgres",
  "engine": "postgresql",
  "memoryMB": 1024,
  "storageGB": 20
}
```

```bash
curl -X PUT https://api.hyzecloud.com/api/apps/app_001/env \
  -H "Authorization: Bearer hyze_sua_chave" \
  -H "Content-Type: application/json" \
  -d '{ "envVars": { "DATABASE_URL": "postgresql://user:pass@host:5432/db" } }'
```

<Callout type="warning">
  Trate a string de conexão como segredo. Ela dá acesso total aos dados. Não commite, não cole em logs e rotacione a senha se vazar — `POST /api/databases/:id/rotate-password`.
</Callout>

## Operação

A Hyze cuida do ciclo de vida: start, stop, estatísticas, logs, backups e restauração. Tudo disponível pela [API de bancos](/api-reference/databases).

Por padrão, a criação usa `memoryMB: 512` e `storageGB: 5` (mínimo 256 MB e 1 GB).
