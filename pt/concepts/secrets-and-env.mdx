Variáveis de ambiente configuram seu app em runtime — sem rebuild, sem commit. A Hyze armazena os valores junto ao app e os injeta quando o processo inicia.

## Quando usar

Use variáveis de ambiente para:

- URLs de banco (`DATABASE_URL`)
- Chaves de API de serviços externos
- Segredos de sessão e webhook
- Feature flags e configuração por ambiente

```json
{
  "envVars": {
    "NODE_ENV": "production",
    "DATABASE_URL": "postgresql://user:pass@host:5432/db"
  }
}
```

## Regras que a API impõe

A API rejeita chaves reservadas como `NODE_ENV`, `PORT`, `PATH`, `HOME` e prefixos como `HYZE_`, `DOCKER_`, `AWS_`. Prefira nomes da aplicação: `APP_ENV`, `DATABASE_URL` e afins.

`PUT /api/apps/:appId/env` faz merge das variáveis enviadas no ambiente existente — não substitui tudo.

## Bom senso

- Não commite segredos no controle de versão
- Use nomes de variáveis claros e descritivos
- Rotacione chaves vazadas imediatamente
- Mantenha valores de produção e desenvolvimento separados

## Mudou a variável? Reinicie

Variáveis são injetadas **na inicialização do processo**. Depois de atualizar valores usados durante o boot, reinicie o app.
