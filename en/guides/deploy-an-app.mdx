Use the Apps API when you want deploys from CI/CD, internal tools, or your own control panel. Two paths: upload a ready ZIP or point to a connected GitHub repository.

## Choose a deploy source

| Source | Best for |
| --- | --- |
| [ZIP](#deploy-from-a-zip) | Build artifacts produced by CI |
| [GitHub](#deploy-from-github) | Source code in a connected repo, with auto deploy |

## Deploy from a ZIP

<Steps>
  <Step title="Package your app">
    Create a ZIP with the files Hyze should run: your app's entrypoint and dependency manifest.
  </Step>
  <Step title="Send the deploy request">
    ```bash
    curl -X POST https://api.hyzecloud.com/api/apps/deploy \
      -H "Authorization: Bearer hyze_your_key" \
      -F "file=@app.zip" \
      -F "name=my-api" \
      -F "runtime=node" \
      -F "memoryMB=512" \
      -F "exposePort=3000"
    ```

    `startupCommand` is optional. Omit it (or use `auto`) and Hyze detects the right command. Override only if needed: `-F "startupCommand=node server.js"`.
  </Step>
  <Step title="Verify the result">
    Poll `GET /api/apps/:appId` until `status: running`, then open the logs:

    ```bash
    curl "https://api.hyzecloud.com/api/apps/app_001/logs?tail=200&timestamps=true" \
      -H "Authorization: Bearer hyze_your_key"
    ```
  </Step>
</Steps>

## Deploy from GitHub

Use [`POST /api/apps/deploy-from-repo`](/api-reference/apps#deploy-from-github-repo) after connecting GitHub in the dashboard:

```json
{
  "name": "my-api",
  "runtime": "node",
  "memoryMB": 512,
  "exposePort": 3000,
  "autoDeploy": true,
  "repository": {
    "id": "repo_001",
    "owner": "hyzecloud",
    "name": "my-api",
    "branch": "main"
  }
}
```

<Tip>
  With `autoDeploy: true`, pushes to the branch trigger new deploys automatically.
</Tip>

## Runtimes

| Runtime | Auto detect | Notes |
| --- | --- | --- |
| `node` | Yes (API, static site, Vite, Next…) | Expose the same port your server listens on. |
| `bun` | Yes | Keep the lockfile in the artifact when possible. |
| `python` | Yes | Include your dependency file in the ZIP. |

Optional override examples: `node server.js`, `bun run start`, `python main.py`.

<Callout type="info">
  With an exposed port, pass the **full host** as the subdomain (e.g. `my-api.hyzecloud.app`), not just the prefix.
</Callout>

## Common problems

<AccordionGroup>
  <Accordion title="Deploy finishes but the app doesn't respond">
    Check `exposePort` and that your server listens on `0.0.0.0`. Read the logs to rule out a boot crash.
  </Accordion>
  <Accordion title="Wrong start command">
    Pass `startupCommand` to override (e.g. `node server.js`) or leave it out for default detection.
  </Accordion>
</AccordionGroup>
