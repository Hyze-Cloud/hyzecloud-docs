---

This is the shortest deploy path for CI systems that produce a ZIP artifact: one `curl`, no SDK.

## Deploy

```bash
export HYZE_API_KEY="hyze_your_key"

curl -X POST https://api.hyzecloud.com/api/apps/deploy \
  -H "Authorization: Bearer $HYZE_API_KEY" \
  -F "file=@app.zip" \
  -F "name=my-api" \
  -F "runtime=node" \
  -F "memoryMB=512" \
  -F "exposePort=3000"
```

`startupCommand` is optional. Omit it (or use `auto`) and Hyze detects the right command. Override only if needed:

```bash
  -F "startupCommand=node server.js"
```

## In a CI script

```bash
#!/usr/bin/env bash
set -euo pipefail

response=$(curl -sf -X POST https://api.hyzecloud.com/api/apps/deploy \
  -H "Authorization: Bearer $HYZE_API_KEY" \
  -F "file=@app.zip" \
  -F "name=my-api" \
  -F "runtime=node" \
  -F "memoryMB=512" \
  -F "exposePort=3000")

echo "Deploy sent: $response"
```

`set -euo pipefail` makes the pipeline fail if the deploy fails — no silently broken deploys.

## Verify

```bash
curl https://api.hyzecloud.com/api/apps/ \
  -H "Authorization: Bearer $HYZE_API_KEY"
```
